## 🛠️ Tech Stack & Architecture
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **State Management**: React Context + Hooks + LocalStorage Persistence
- **Design System**: Light / Dark dual theme with high contrast, glassmorphism cards, and smooth micro-animations
- **CI/CD**: Automated GitHub Actions deployment pipeline for GitHub Pages

## 📦 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AhmedHesham2112/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local dev server**:
   ```bash
   npm run dev
   ```

4. **Build production bundle**:
   ```bash
   npm run build
   ```
